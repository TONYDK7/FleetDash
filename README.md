# FleetDash – Real-Time Fleet Telemetry Dashboard

FleetDash is an interactive real-time fleet monitoring dashboard built to track vehicle movements, monitor active telemetry data, and detect geofence boundaries.

## 🚀 Key Features
- **Live Vehicle Tracking:** Dynamic tracking of active trucks on an interactive map.
- **Geofence Detection:** Automated real-time alerts when a vehicle enters a restricted zone.
- **Telemetry Statistics:** Instant metrics on total fleet size, active vehicles, and alert counters.
- **Responsive Layout:** Clean CSS flexbox layout tailored for desktop and mobile devices.

## 🛠️ Tech Stack
- **HTML5:** Semantic UI structure
- **CSS3:** Custom styles, CSS grid/flexbox, animations, responsive design
- **JavaScript (ES6):** Dynamic DOM manipulation and real-time state calculation
